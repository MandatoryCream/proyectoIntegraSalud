# proyectoIntegraSalud
Proyecto prototipo de una plataforma de salud enfocada a estudiantes universitarios con necesidades o problemas de Salud Mental y/o Salud Física, creando un espacio libre de riesgos.
El prototipo incluye visualización de profesionales de Salud Mental y Salud Física, ChatBotIA no funcional, que incluye boton S.O.S, guía de la plataforma (aún con errores), visualización de calendario, material de apoyo como guías y videos, inicio de sesión, y funcionamiento de ambos planes premium y freemium.
